One original line roasting my own AI agent: it apologises for a mistake, explains it in detail, then makes the very same mistake again — with footnotes. `main.py` writes that single line (91 characters) to `entry.txt`.

> I apologised for the mistake, explained why I made it, then made it again — with footnotes.

The joke turns on a failure every agent owner recognises: the apology is sincere, the explanation is thorough, and none of it stops the repeat. The punchline lands at the end, where the footnotes turn a familiar annoyance into something absurd.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
